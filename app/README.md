# موقع رواية «موري» — محمد طايع

موقع بيع الرواية بالكامل (PDF) مع لوحة تحكم، جاهز للرفع على GitHub Pages مجاناً.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية (الواجهة، الفصل المجاني، الشراء) |
| `style.css` | التصميم (مشترك بين الموقع واللوحة) |
| `script.js` | الدفع والإحصائيات وقراءة إعدادات اللوحة |
| `admin.html` + `admin.js` | لوحة التحكم |
| `mory-cover.jpg` | الغلاف الأمامي للجزء الأول |
| `mory.pdf` | رواية الجزء الأول (71 صفحة) |
| `mory-back.jpg` | الغلاف الخلفي للجزء الأول (اختياري) |
| `mory-hero.jpg` | غلاف الموقع — خلفية الواجهة (اختياري، من اللوحة) |
| `mory2.pdf` | الجزء التاني (بيتضاف لما يجهز) |
| `mory2-cover.jpg` / `mory2-back.jpg` | أغلفة الجزء التاني (اختياري) |
| `scene-nile.jpg` / `scene-mory.jpg` / `scene-sorcerer.jpg` / `scene-love.jpg` | صور قسم «من أجواء الرواية» — ممكن تستبدلها بصورك |
| `qr-instapay.jpg` / `qr-vodafone.jpg` | أكواد الدفع للمسح المباشر (بتترفع من اللوحة) |
| `settings.json` | الأرقام واللينكات (التواصل، الأسعار) — نزّله من اللوحة وارفعه بعد التعديل |

## الدفع بالمسح المباشر (QR)

من غير ما تستنى موافقة Paymob: ارفع من اللوحة كود إنستا باي وكود فودافون كاش،
نزّلهما بأسماء `qr-instapay.jpg` و `qr-vodafone.jpg` وارفعهما على GitHub.
المشتري بيضغط «اشترِ» ← «مسح كود تحويل مباشر» ← يمسح ويحوّل، وبعدها يضغط
«أنا حوّلت» فتفتحله محادثة واتساب فيها تفاصيل طلبه — تتأكد من التحويل وتبعتله الرواية.

## الرفع على GitHub Pages (خطوة بخطوة)

1. اعمل حساب على github.com واعمل New Repository جديد (خليه Public).
2. ارفع كل الملفات اللي في المجلد ده على المستودع (Add file > Upload files).
3. من Settings > Pages: اختار Branch = `main` واضغط Save.
4. بعد دقيقتين هيبقى موقعك شغال على: `https://اسم-المستخدم.github.io/اسم-المستودع/`
5. لو عندك دومين `mtayea.com`: في نفس صفحة Pages اكتبه في Custom Domain، وفي إدارة الدومين اعمل سجلين:
   - `A` للنطاق الرئيسي → `185.199.108.153` (و 109 و 110 و 111)
   - `CNAME` للـ www → `اسم-المستخدم.github.io`
6. فعّل Enforce HTTPS من نفس الصفحة.

## لوحة التحكم

- افتح: `رابط-موقعك/admin.html`
- كلمة السر الافتراضية: `mory-2026`
- **غيّرها قبل النشر**: افتح `admin.js` وعدل أول سطر `const ADMIN_PASSWORD`.

### من اللوحة تقدر:

1. **الإحصائيات**: عدد الزيارات، بدء قراءة الفصل، فتح نافذة الشراء، محاولات الدفع، عمليات الشراء الناجحة، ونسبة الشراء من الزيارات + رسم بياني يومي آخر 14 يوم.
   - ملحوظة: الأرقام دي محلية (بتتسجل في متصفح كل زائر على جهازه). الأرقام الشاملة لكل الزوار: فعّل GoatCounter المجاني، وعمليات الشراء كلها في لوحة Paymob > التقارير.
2. **تغيير الأسعار** والتحكم في عنوان الجزء التاني وسعره.
3. **رفع الأغلفة** الأمامي والخلفي وملف الجزء التاني PDF.
4. **أكواد الدفع QR**: رفع كود إنستا باي وكود فودافون كاش (انظر قسم «الدفع بالمسح المباشر» فوق).
5. **وسائل التواصل**: رقم الواتساب ورابط الفيسبوك والإيميل والتليفون — الأيقونات بتظهر في آخر الموقع.
   بعد ما تملاهم دوس «حفظ الإعدادات» وبعدين «تنزيل settings.json للرفع على GitHub» وارفع الملف النازل.

### إزاي أنشر الجزء التاني للزوار كلهم؟

الرفع من اللوحة بيظهر في **متصفحك أنت فوراً**. عشان يظهر لكل الزوار:

1. من اللوحة: ارفع `mory2.pdf` ودوس «تنزيل للرفع على GitHub».
2. ارفع الملف النازل على المستودع بنفس الاسم `mory2.pdf`.
3. من اللوحة فعّل «إظهار الجزء التاني في الموقع» ودوس حفظ.
4. نفس الفكرة للأغلفة: `mory-cover.jpg` (أمامي) و`mory-back.jpg` (خلفي).

> ملحوظة أمان: حماية اللوحة بكلمة سر حماية عرض بسيطة (الموقع ثابت من غير سيرفر). متمنتحاش في اللوحة بيانات حساسة — كلمة سر Paymob مثلاً متتحطش فيها.

## تفعيل الدفع (Paymob)

1. سجّل في paymob.com وأكّد حسابك.
2. من Developers > API Keys خد الـ API Key.
3. فعّل وسائل الدفع (كارت / محافظ إلكترونية / إنستا باي / فوري) وخد رقم Integration ID لكل وسيلة.
4. افتح `script.js` وعبّي القيم في `CONFIG.paymob`.
5. **مهم جداً**: في إعدادات كل integration حط Redirect URL = رابط موقعك — دي اللي بترجع العميل لصفحة التحميل بعد الدفع.
6. حط رقم الواتساب في `CONFIG.whatsappNumber` بصيغة دولية بدون + (مثال: 2010xxxxxxxx).
7. غيّر السعر من `CONFIG.priceEgp` لو عايز.
8. جرّب عملية شراء تجريبية قبل نشر الرابط.

## حماية ملف الـ PDF (مهم)

ملف الـ PDF حالياً في المستودع العام، يعني أي حد بيفهم يقدر يلاقي رابطه ويحمّله من غير دفع.
الحل الحقيقي: سيرفر صغير (زي Cloudflare Worker أو Netlify Function) يدي رابط تحميل موقّع بعد التحقق من العملية — الكود جاهز يستقبل الخطوة دي. لو حابب نعملها قولّي.
