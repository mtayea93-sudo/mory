# موقع رواية «موري» — ملف الرفع على GitHub Pages

النسخة الكاملة لموقع الرواية (الجزء الأول + الجزء الثاني).
ارفع **كل الملفات والمجلدات** الموجودة هنا إلى ريبو GitHub بتاعك
ثم فعّل GitHub Pages من إعدادات الريبو (Branch: `main` / root).

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية للموقع |
| `style.css` | التصميم (ألوان، خطوط، تنسيق كامل) |
| `script.js` | منطق الموقع (التحميل، الدفع، الأقسام) |
| `admin.html` / `admin.js` | لوحة التحكم (افتحها من `admin.html` بعد الرفع) |
| `settings.json` | الإعدادات المركزية (الأسعار، الجزء التاني، التواصل، QR) |
| `qrcode.min.js` | مكتبة توليد أكواد QR داخل المتصفح (بدون إنترنت) |
| `mory.pdf` | ملف الجزء الأول (71 صفحة) — بيتحمّل بعد الدفع |
| `mory-cover.jpg` | الغلاف الأمامي للجزء الأول |
| `scene-nile.jpg` / `scene-mory.jpg` / `scene-sorcerer.jpg` / `scene-love.jpg` | صور معرض مشاهد من الرواية |

## الإعدادات (settings.json)

كل حاجة بتتغير من **لوحة التحكم** أو من الملف مباشرة:

- `pricePart1` — سعر الجزء الأول (جنيه).
- `part2` — بيانات الجزء التاني: `title`, `price`, `published` (true = الظهور، false = «في مرحلة التجهيز»).
- `contact` — واتساب / فيسبوك / إيميل / تليفون (الأيقونات بتظهر في الفوتر لو مكتوبة).
- `qr` — `instapay` (لينك إنستا باي) و `vodafone` (رقم فودافون كاش).
  **الموقع بيولّد أكواد QR تلقائيًا** من القيم دي — مش محتاج ترفع صور QR.

## لوحة التحكم

1. افتح `https://موقعك/admin.html`.
2. كلمة السر الافتراضية: `mory-2026` — **غيّرها فورًا من أول سطر في `admin.js`**
   (`const ADMIN_PASSWORD = '...';`) قبل ما تعلن الموقع.
3. املأ اللي عايزه: الأسعار، حالة الجزء التاني، الغلاف، ملف PDF،
   بيانات التواصل، ولازم **تحفظ** في الآخر.
4. عشان الزوار كلهم يشوفوا التعديلات: اضغط **«تنزيل settings.json للرفع على GitHub»**
   وارفع الملف الجديد مكان القديم في الريبو.
   (الغلاف/الـ PDF لو رفعتهم كمان للريبو بنفس الأسماء المكتوبة في اللوحة هيشتغلوا
   تلقائيًا حتى من غير تنزيل الملف.)

## طرق الدفع

- **Paymob**: حط الـ API Keys بتاعتك في `script.js` (ثوابت `CONFIG` في أول الملف).
- **تحويل مباشر QR**: العميل يختار «مسح كود تحويل مباشر» من الشاشة،
  يختار إنستا باي أو فودافون كاش، يمسح الكود اللي اتولّد تلقائيًا،
  وبعدها يتأكد فيظهر له زرار واتساب جاهز باسم الرواية والمبلغ.

## ملاحظات مهمة

- التعديلات من اللوحة بتتحفظ في **متصفحك أنت بس** — عشان الكل يشوفها لازم
  تنزّل `settings.json` وترفعه على GitHub (الزرار موجود في اللوحة).
- أي تعديل في الكود نفسه لازم يرفع للريبو عادي.
- بعد الرفع خلّي الزوار يعملوا **Ctrl+F5** عشان يشوفوا النسخة الجديدة.
