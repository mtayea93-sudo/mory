مفيش ملف مرفوع

مهم: الرفع هنا بيظهر في متصفحك أنت بس فوراً. عشان يظهر لكل الزوار: ارفع الملف هنا، دوس «تنزيل للرفع على GitHub»، وبعدين ارفع الملف النازل في مستودع GitHub بنفس الاسم (mory-cover.jpg / mory-back.jpg / mory2.pdf).

تفعيل الدفع الإلكتروني (Paymob)

  1. سجّل في paymob.com وأكّد حسابك التجاري.
  2. خد API Key من Developers > API Keys.
  3. فعّل وسائل الدفع اللي عايزها (كارت / محافظ / إنستا باي / فوري) وخد رقم كل Integration ID.
  4. افتح ملف script.js وعبّي القيم في CONFIG.paymob.
  5. في إعدادات كل integration حط Redirect URL = رابط موقعك — عشان العميل يرجع لصفحة التحميل بعد الدفع.
  6. جرّب عملية شراء بجنيه واحد قبل ما تنشر الرابط.
